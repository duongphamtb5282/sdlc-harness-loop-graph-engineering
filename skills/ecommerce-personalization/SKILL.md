# E-commerce & Personalization

*Search, recommendations, catalog, and checkout — engineered for conversion and scale.*

## What it covers

- Search and discovery: relevance ranking, faceting, typo tolerance
- Recommendation systems: collaborative filtering, content-based, hybrid
- Personalization: segmentation, experimentation, A/B testing infrastructure
- Checkout and order flows: cart integrity, payment orchestration, idempotency
- Catalog and inventory systems: pricing, promotions, multi-tenant data models

## What you receive

- Commerce architecture with API contracts and data models
- Search/recommendation design with ranking strategy documented
- Order-flow design with failure and retry semantics
- Test cases covering the revenue-critical journeys

## When to use it

You run a store, marketplace, or digital commerce product and need it to scale past hand-built flows.
