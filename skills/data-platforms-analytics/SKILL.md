# Data Platforms & Analytics

*Warehousing, pipelines, and analytics — from raw sources to decision-ready data.*

## What it covers

- Data architecture: lake/warehouse/mesh patterns, schema design, modeling
- Pipeline engineering: ingestion, transformation, orchestration, backfills
- Analytics engineering: metrics definitions, marts, dashboards that match business language
- Quality: data contracts, validation gates, lineage, reconciliation
- Cost visibility: query economics, storage tiering, workload partitioning

## What you receive

- Data platform architecture with storage and pipeline design
- Data model and schema designs with naming and contract standards
- Pipeline design with failure, retry, and backfill semantics
- Implementation plan with quality gates and test cases

## When to use it

You're building a reporting platform, a data warehouse, or a product that needs trustworthy numbers at scale.
