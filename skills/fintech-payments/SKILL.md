# Fintech & Payments

*Payment flows, ledgering, and financial security — where correctness is non-negotiable.*

## What it covers

- Payment orchestration: acquiring, wallets, payouts, reconciliation
- Ledgering: double-entry design, idempotent money movement, audit trails
- KYC/AML integration: identity verification, screening, monitoring
- Financial security: tokenization, key management, PCI-scope minimization
- Regulatory readiness: data residency, retention, evidence chains

## What you receive

- Payment architecture with money-flow invariants documented
- Ledger and data models with audit and reconciliation design
- Security architecture: key handling, tokenization, least privilege
- Review report covering financial correctness and compliance exposure

## When to use it

You're building or extending money-handling software where a rounding bug is an incident.
